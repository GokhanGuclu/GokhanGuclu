## 🏆 Featured Projects

### ⚡ OmniFiles &nbsp;·&nbsp; `Live on Microsoft Store`

[![Microsoft Store](https://img.shields.io/badge/Microsoft_Store-Get_it-0078D4?style=flat-square&logo=microsoftstore&logoColor=white)](https://apps.microsoft.com/detail/9NWFH3FLSHPT)

File Explorer, rebuilt for speed. A native Windows file manager that looks and feels like the Explorer you already know, but opens folders with 100,000+ files in milliseconds and never freezes the UI — even when a network drive stops responding. Turkish & English, 100% offline, no telemetry.

| First rows visible | Full listing | Sort 100k items | Warm startup |
|:---:|:---:|:---:|:---:|
| **~23 ms** | **~72 ms** | **~95 ms** | **~260 ms** |

**Technologies:**
- Framework: .NET 10, C#, WinUI 3, Native AOT
- System: Win32 API (`FindFirstFileExW`), virtualized UI, parallel merge-sort

### 🎛️ [SoundDeck](https://github.com/GokhanGuclu/SoundDeck) &nbsp;·&nbsp; `Live on Microsoft Store`

[![Microsoft Store](https://img.shields.io/badge/Microsoft_Store-Download-0078D4?style=flat-square&logo=microsoftstore&logoColor=white)](https://apps.microsoft.com/detail/9N0LNT66JHZW)
[![Source](https://img.shields.io/badge/Source-GitHub-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/GokhanGuclu/SoundDeck)
[![License](https://img.shields.io/badge/License-MIT-green.svg?style=flat-square)](https://github.com/GokhanGuclu/SoundDeck/blob/main/LICENSE.txt)

An audio control center for Windows. Switch between your headset and speakers, toggle between two microphones and control volume — all with global hotkeys, straight from the system tray. Runs quietly in the background with no ads, no telemetry and no account required.

> Published on the Microsoft Store under the name **SoundPilot**.

**Technologies:**
- Framework: .NET 10, C# 14, Windows Forms
- System: Win32 API (global hotkeys), AudioSwitcher CoreAudio
- Packaging: Velopack (auto-updates), Inno Setup, PowerShell

### 🎮 [PS5 Altyazı Çevirici](https://github.com/GokhanGuclu/ps5-altyazi-cevirici)

Translates English in-game subtitles into Turkish in real time, running entirely on your own PC. It reads the subtitle from the game feed, translates it on the GPU and overlays the translation on the stream through OBS — no internet connection, account or paid translation service needed. It even detects speaker names by color and keeps them untranslated.

**Technologies:**
- Language: Python
- OCR & Translation: Tesseract OCR, Meta NLLB-200, PyTorch (CUDA)
- Integration: OBS Virtual Camera, OBS browser source

### 📬 [MailMind](https://github.com/GokhanGuclu/MailMind)

Backend platform for multi-provider mailbox management and account-level authentication. A modular monolith with a full IAM module (Argon2 password hashing, JWT access/refresh tokens with rotation, database-backed sessions) and a worker-driven mailbox sync pipeline, covered by e2e tests.

**Technologies:**
- Backend: NestJS, TypeScript
- Database: PostgreSQL, Prisma
- Infrastructure: Docker, background workers

### 🔍 [SyntaxSherlock](https://github.com/GokhanGuclu/SyntaxSherlock-RuntimeError)

Predicts Python runtime errors (ZeroDivisionError, IndexError, …) before the code ever runs. Each line gets a 0–1 risk score from a Random Forest model with 90%+ accuracy, combined with static analysis for definite errors. Built together with a friend.

**Technologies:**
- Frontend: React 19, TypeScript
- Backend: Python, FastAPI, REST API
- Machine Learning: Scikit-learn (Random Forest)
